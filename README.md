# Lexie RAG Lab 1.1

用金融教学案例观察「检索增强生成」的每一步。松石绿、简洁留白，支持浅色、深色与系统主题。

## Windows 启动

1. 将整个 ZIP 解压到一个固定文件夹。不要在压缩包里面直接运行。
2. 电脑需安装 Node.js **20或以上版本**。不需要运行 npm install。
3. 双击 **启动RAG-Lab.bat**。
4. 浏览器打开 http://127.0.0.1:3220 。启动窗口需要保留，关闭后网页服务停止。
5. 点「运行第一个实验」：自动载入教学资料、建立索引并运行第一个问题。

也可以在此文件夹的 PowerShell 输入 `node server.mjs`。macOS / Linux 使用 `sh start.sh`。

网页不是单文件 HTML，请不要直接双击 public/index.html。
端口冲突时关闭已开启的同一程序。自定义端口可在 PowerShell 运行 `$env:PORT=3221; node server.mjs`，然后访问新端口。

## 先学什么

- **学习概览**：知识库与 RAG 的关系，资料准备和查询生成两个阶段。
- **资料与建库**：载入案例或导入资料；调整固定/结构分块、重叠、标题等元数据；查看原文、分块、向量前12维。
- **问答实验**：切换关键词、向量、混合检索，按产品/年份过滤，调整候选数、最终资料数和字符预算，查看全部输入输出。
- **对比与评估**：A为关键词已保存的基线（可编辑），B为当前配置，两组使用同一索引与每道题标注的过滤条件。
- **金融案例**：疾病与意外等待期、既往症、理赔材料、犹豫期、年报口径、资料不足。
- **实验历史**：重看证据快照、导出完整备份、恢复备份。
- **原理与来源**：概念辨析、课件校正和一手论文/官方工程文档链接。
- **模型连接**：填写独立生成、Embedding 和可选 Rerank 服务。

## 教学模式与真实模式

| 项目 | 教学探索 | 真实实验 |
| --- | --- | --- |
| 是否需要密钥 | 不需要 | 需要配置对应服务 |
| 关键词检索 | 实际计算的 BM25，中文使用二字词项 | 同左 |
| 向量 | 96维哈希词项与预设同义词特征，**不是语义模型** | 服务商返回的真实 Embedding |
| 混合检索 | 实际 RRF 排序融合，常数60 | 同左 |
| 问题改写 | 明确的教学同义词规则 | 生成模型调用 |
| 重排 | 教学词项覆盖规则，**不是重排模型** | Rerank API |
| 回答 | 检索原文摘录，**不是 AI 生成答案** | 生成模型实际回答 |
| 指标 | 只用于理解本教学算法 | 反映这次真实配置和测试集 |

更复杂的配置不保证更好。Rerank不能恢复初次检索未找到的资料。10%～20%重叠、最终3～5块都是实验起点，不是行业标准。
标题上下文功能只补已有元数据，不等同于 Anthropic 的 LLM Contextual Retrieval。

## 连接真实模型

1. 打开「模型连接」。填写并分别测试生成模型、Embedding 模型。
2. Base URL 填接口前缀，例如 `https://服务商/v1`；程序自动追加路径。不要把密钥放进 URL。
3. 生成模型使用 `POST /chat/completions`：OpenAI兼容 messages、choices[0].message.content 格式。可配置 DeepSeek 等兼容服务；模型ID以服务商当前提供的为准。
4. Embedding 使用 `POST /embeddings`：支持 input 数组，返回 data[index, embedding]。文档与问题必须使用同一个 Embedding 服务和模型。
5. Rerank 使用 `POST /rerank`：输入 model、query、documents、top_n、return_documents:false，返回 results[index,relevance_score]。并非所有供应商接口都兼容。
6. 在右上角切到「真实实验」，重新建立索引。模型或建库参数变化会要求重建。
7. 如没有 Rerank 服务，在「问答实验」取消候选重排，再运行问题。

生成模型、Embedding 和 Rerank 是不同能力，不假定一个密钥或模型支持所有接口。
密钥只在当前网页内存及请求中使用；刷新页面后清空。不会保存至历史、备份或服务端数据文件。
真实调用会消耗对应服务商额度，建库发送文档块到 Embedding 服务，改写发送问题，重排发送候选，回答发送问题及选中证据。请使用适合这些资料的服务。

## 资料导入

- TXT / Markdown：直接支持，也可以粘贴正文。每份最多50万字符，最多100份，总共200万字符。
- PDF：最大10MB、500页。本版已内置pypdf解析组件，电脑仍需Python 3.9或以上；不需要单独pip安装。
- 扫描件没有 OCR；程序会提示。复杂表格不保证保留结构；导入后请核对原文、数值和单位。图片、网页抓取、Excel解析不在第一版范围。
- 可选清洗会规范换行并删除重复非空行，**可能改变原文**，默认关闭。重要条款建议先保留原文。
- 每次新增/移除资料，索引失效，需要重新建库。个人版索引上限1200块。
- 所有内置保险、企业、年报和风险概念资料为自编虚构教学材料，不代表真实产品条款或企业事实。

## 历史和备份——请先看这里

- 文档、完整向量索引、最多200次问答及30次评估保存在 **项目文件夹/data/state.json**。刷新网页或重启服务不会丢失。
- 文件使用临时文件＋重命名原子写入。文件损坏时不会静默清空覆盖。
- 请固定使用同一解压文件夹。换一个新文件夹就是另一个数据目录。
- 更新程序前，在「实验历史」点「导出完整备份」。更新后恢复备份，或复制旧 data 文件夹到新项目。
- 导出包含文档、问题、回答、配置与证据快照，**不含向量索引和API密钥**。恢复后重新建库。
- 恢复会替换当前数据，服务先保存恢复前文件为 `data/state.json.before-restore.bak`。
- 最好在不同磁盘再放一份备份。不要同时启动两个服务进程写同一个 data 文件夹。
- 历史中的原文证据保留快照；当前资料变化后，仍能看到当次实际使用的内容。

## 评估怎么读

预置5道有完整证据标注的问题，另有1道资料不足案例。1.1新增“我的测试题”、当前问题直接A/B及可编辑A组基线。两组使用相同资料过滤范围。

- 最终证据召回率：最终上下文包含的标准引文数 / 标准引文总数。
- 候选证据召回率：初次检索候选包含的标准引文数 / 标准引文总数。
- 证据精确率：至少包含一个完整标准引文的选中块数 / 选中块数。
- 匹配采用文档ID＋完整引文精确匹配；切断引文时，即使跨块拼起来能读到，也会被这个严格指标判为未命中。重复命中同一标准证据只计一次召回。
- 无标注问题显示“未评估”。1.1支持自定义题目与原文证据标注，不使用LLM自动裁判。
- 回答准确性、引用是否支持结论不能从检索分数推出，需要人工核对。可在问答记录中保存“正确/部分正确/错误”。引用编号有效也不代表内容支持结论。
- 延迟是本次实测；教学延迟不能用来预测真实模型延迟。字符预算不是 Token 预算；实际 Token 用量仅显示服务商返回的 usage。

## 实现与边界

Node.js标准库服务＋原生 HTML/CSS/JavaScript，零 npm 运行依赖。持久化为本地 JSON，向量相似度为穷举余弦，适合个人小规模实验，不是企业生产级向量数据库。
默认只监听127.0.0.1，没有多人登录、权限管理、加密存储或跨设备同步。请不要直接暴露服务到公网。GitHub Pages 不能运行本地 Node 服务，也不能自动同步此 data 文件夹。
本版不包含 GraphRAG、Agentic RAG、多模态检索、自动财务计算或投资/理赔决策；来源页面解释它们与经典链路的关系。

## 开发与测试

```sh
node --test test/*.test.mjs
```

覆盖分块、过滤、指标、持久化、API完整流程及真实模型适配器协议。协议测试使用本地测试服务，不等于完成某个付费服务商的实网认证。

文件结构：
- `server.mjs`：HTTP接口与导入、存储、问答、评估路由。
- `lib/core.mjs`：分块、BM25、特征向量、RRF、上下文、证据评估。
- `lib/pipeline.mjs`：建库与问答链路。
- `lib/providers.mjs`：真实模型接口。
- `lib/store.mjs`：原子存储与备份恢复。
- `lib/samples.mjs`：自编教学资料及标准证据。
- `public/`：完整前端。

原理依据与链接见「原理与来源」。课程PPT只作为评审输入，不随程序分发。
## Vercel deployment

This package includes `api/index.mjs` and `vercel.json` for a Vercel Node.js
Serverless Function deployment. Import the repository in Vercel with the
repository root as the project root; no custom start command is required.

The local launcher remains available for Windows. Online state is temporary and
is stored in Vercel's writable `/tmp` space, so use the online version for
teaching and interviews rather than as a permanent production knowledge base.
