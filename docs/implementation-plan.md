# RAG Lab Implementation Plan
Goal: 可观察、可对比、可持久保存的个人 RAG 学习实验室。
Architecture: Node 20+ 零 npm 依赖本地服务，原生前端，JSON 原子存储；文本与 Markdown 原生导入，PDF 可选 Python pypdf 解析。默认 127.0.0.1:3220。
Spec: 用户批准的教学＋真实模式方案；保险条款案例优先。
## Global constraints
- 教学数值向量与规则精排明确标记；真实模式不降级假回答。
- 外部模型密钥只在请求和内存中；不保存到历史、备份、日志。
- 真实生成、Embedding、Rerank 独立设置；支持兼容 Chat Completions / embeddings / rerank 的服务。
- 所有演示金融数据均为虚构，不复用课件内容作为商用资料。
## Tasks
1. 数据和检索核心：清洗、结构/定长切块、BM25、教学向量、RRF、过滤、上下文与评估；先写并运行测试，再实现。
2. 模型适配和本地服务：真实 Embedding / Query 改写 / 重排 / 生成；存储、历史、导入导出与端点测试。
3. 界面：概念、建库、问答、评估、案例、历史、连接；浅深主题、响应式、隐藏滚动条与减少动画。
4. 验收：核心及 HTTP 集成测试、浏览器操作、PDF 解析、启动与 ZIP 保存。
## Review focus
空文件与空问题；重叠不允许死循环；旧版/错误产品过滤；凭证不进入导出；标注缺失时指标为空；失败模型调用明确报错；索引模型变化必须重建；数据导入先验证再写入；并发写入不丢失。
